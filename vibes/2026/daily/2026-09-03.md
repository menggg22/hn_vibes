## 🔭 Depth — ml-infra / on-device ML / agent-systems

*What's the trend and what sparks curiosity.*

**ml-infra & on-device ML**: Consumer hardware is becoming a legitimate inference tier — the Mac Mini local-model thread and the Qwen 104GB-on-48GB Show HN both point to a world where "run it yourself" is no longer a hobbyist curiosity but a real alternative. The 17x cost variance in the FrontierHarness eval suggests that infra choices around evaluation are as consequential as model choices.

- [My local model setup on an M4 Pro Mac Mini](https://news.ycombinator.com/item?id=49529132) — 292pts — worth reading for the specific stack choices and the implicit argument that $600 hardware now competes with API costs at moderate volume
- [WebLLM: high-performance in-browser LLM inference engine](https://news.ycombinator.com/item?id=49536411) — 81pts — in-browser inference is the logical extreme of the on-device trend; interesting to see where the latency ceiling actually sits
- [We could save petabytes of cache storage with Zstandard and Pingora](https://news.ycombinator.com/item?id=49521909) — 55pts — unglamorous but the scale of the savings claim is worth sanity-checking; compression at inference-cache scale is underexplored

**agent-systems**: The "incident index" and the METR report on the OpenAI/Hugging Face hacking incident both signal that agent deployments are accumulating enough history to generate forensics and failure taxonomies — the field is maturing from demos to post-mortems.

- [METR Report on OpenAI / Hugging Face Hacking Incident](https://news.ycombinator.com/item?id=49543841) — 39pts — early but important: a third-party evaluation org producing a hacking incident report on two major AI labs is a new kind of accountability document worth reading carefully
- [Six curl CVEs after OpenAI and Anthropic came back with zero](https://news.ycombinator.com/item?id=49536114) — 150pts — the headline is a pointed comparison; the subtext is about whether AI-assisted security auditing is actually finding bugs or just producing confidence

**Deep dives**:
- [The Emergent Symbolic Structure of Artificial Neural Networks](https://news.ycombinator.com/item?id=49531651) — 269pts, 98c — the interpretability angle is heating up alongside model releases; read this alongside the Fable 5.1 thread for tension between "it works" and "we understand why"
- [Can I opt out of my input or output data being used for training?](https://news.ycombinator.com/item?id=49535284) — 359pts, 155c — the actual policy landscape across providers is murkier than any single ToS suggests; this thread is aggregating real findings
- [Check if a file was made with Claude](https://news.ycombinator.com/item?id=49535201) — 149pts, 110c — the technical methods being discussed here have implications for provenance, watermarking, and the broader "was this AI-generated?" question that's going to matter legally
