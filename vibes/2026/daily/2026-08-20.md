## 🔭 Depth — ml-infra / on-device ML / agent-systems

*What's the trend and what sparks curiosity.*

**ml-infra & on-device ML**: On-device inference is quietly crossing a threshold — 10M tokens per second on Apple Silicon is no longer a research number, it's a shipping number. Simultaneously, quantization (Unsloth Dynamic GGUFs) is getting sophisticated enough that the gap between cloud and local is collapsing for most tasks.
- [MicroGPT-C in pure C hits 10M TPS on Apple M5](https://news.ycombinator.com/item?id=49347477) — 118pts — Worth reading for the pure-C implementation details; no frameworks, no abstractions, just metal and math

**agent-systems**: The agent harness space is bifurcating into team-focused sandboxed runners (OneCLI) and open protocol standards (CHAP, AGENTS.md), suggesting the ecosystem is trying to grow up from "vibe-coded scripts" to something teams can actually audit and govern.
- [Feature Request: Support AGENTS.md](https://news.ycombinator.com/item?id=49367350) — 99pts — The push to standardize agent configuration files mirrors how .gitignore and .editorconfig normalized repo conventions; worth watching if this gains cross-tool adoption

**Deep dives**:
- [A decades-old bug in Knuth's long division (TAOCP Vol II, Algorithm 4.3.1D)](https://news.ycombinator.com/item?id=49286258) — If Knuth's most-audited algorithms can carry a latent bug for decades, what does that say about the correctness assumptions baked into every arbitrary-precision library downstream?
- [Chain-of-Thought Reasoning in the Wild Is Not Always Faithful (2025)](https://news.ycombinator.com/item?id=49363587) — Critical reading before shipping any CoT-dependent system; the gap between stated reasoning and actual computation has safety implications that go well beyond benchmarks
- [Extensible Software in the age of LLMs](https://news.ycombinator.com/item?id=49363668) — Asks whether plugin architectures and extensibility primitives designed for humans still make sense when the primary "user" extending your software is an agent; the answer will reshape API design
