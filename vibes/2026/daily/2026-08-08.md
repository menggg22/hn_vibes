## 🔭 Depth — ml-infra / on-device ML / agent-systems

*What's the trend and what sparks curiosity.*

**ml-infra & on-device ML**: The axis of competition is shifting from model quality to inference economics — AMD etching models in silicon, vLLM anatomy posts, and 2027 memory already sold out all point to the same bottleneck: getting tokens out cheaply at scale is now the hard problem, not training. The Postgres 300x analytics speedup via SIMD and operator fusion is a useful parallel — the same batching-and-fusion intuitions from database internals are colonizing ML serving.
- [Making Postgres 300x faster for analytics: batching, operator fusion, and SIMD](https://news.ycombinator.com/item?id=49208535) — 229pts — the techniques here (operator fusion, SIMD vectorization) map almost directly onto LLM inference kernel optimization; worth reading as a mental model transfer

**agent-systems**: Agents are hitting the "trust and permission" inflection point — Claude Code defaulting to auto permission mode on August 14 is a small change with large implications for how much autonomy users will unconsciously grant. Kitesurf's V8 isolate approach and the Channels SDK both suggest the field is bifurcating into sandboxed-safety and open-ended-power camps.
- [Kitesurf: Agent-first browser that runs in V8 isolates](https://news.ycombinator.com/item?id=49208393) — 156pts — isolating agent browser sessions in V8 is an underappreciated security architecture decision; curious how it handles cross-isolate state

**Deep dives**:
- [Inside vLLM: Anatomy of a High-Throughput LLM Inference System (2025)](https://news.ycombinator.com/item?id=49202852) — with 2027 memory sold out, understanding exactly where vLLM spends its memory budget is immediately practical knowledge
- [Oracle bans AI-generated code from OpenJDK](https://news.ycombinator.com/item?id=49213754) — the legal and governance reasoning here will set precedent for every major open-source project; read it before forming an opinion on the next N debates about this
- [Databricks drove down AI coding spend 70%](https://news.ycombinator.com/item?id=49214468) — 153 comments on a cost reduction story means this resonates beyond the headline; the mechanism matters for anyone budgeting AI tooling in 2026
