## 🔭 Depth — ml-infra / on-device ML / agent-systems

*What's the trend and what sparks curiosity.*

**ml-infra & on-device ML**: Two major open-weight model drops in one day (GLM-5.3, Tencent Hy4) plus vLLM 0.28 shipping suggests the inference stack is in a rapid iteration cycle — the gap between frontier closed and capable open is compressing visibly. Samsung's Processing-in-Memory work adds a hardware layer: memory bandwidth is still the wall everyone is running into.
- [Samsung's Processing-in-Memory (PIM)](https://news.ycombinator.com/item?id=49487341) — 241pts — compute-in-memory architectures are quietly becoming the most important hardware story for LLM inference; worth understanding the fundamentals now
- [vLLM v0.28.0](https://news.ycombinator.com/item?id=49492067) — 87pts — the de facto open inference engine keeps shipping; changelogs here telegraph what production LLM serving looks like at scale
- [GLM-5.3 is now open-weight](https://news.ycombinator.com/item?id=49479878) — 780pts — Chinese labs releasing open weights is accelerating; GLM-5.3 joining the pile changes the competitive calculus for anyone building on closed APIs

**agent-systems**: The "LLM memory as program analysis" post is the most intellectually surprising agent story today — accidental discovery of emergent program analysis capability suggests agent architectures are still producing unexpected emergent behaviors that practitioners stumble into rather than design. Domain-driven agents as a framing is also quietly gaining traction as an alternative to raw tool-calling.
- [I accidentally turned LLM memory into program analysis](https://news.ycombinator.com/item?id=49485416) — 272pts — accidental capability discovery in a production agent loop; the "accident" framing is doing a lot of work here and deserves scrutiny
- [Domain-Driven Agents](https://news.ycombinator.com/item?id=49492584) — 36pts — applying DDD vocabulary to agent design is a signal that the field is starting to borrow from mature software architecture rather than reinventing everything

**Deep dives**:
- [GrapheneOS project: pixel 11 no longer supports hardware memory tagging (MTE)](https://news.ycombinator.com/item?id=49490702) — hardware security regression in a flagship device is concerning precisely because MTE was one of the more promising memory-safety mitigations; the "why" buried in this thread matters
- [Just the rumour of a bug is enough to find an exploit these days](https://news.ycombinator.com/item?id=49480466) — 376pts — the attack surface meta-problem: disclosure timing is now weaponized before patches ship, which changes the entire responsible disclosure calculus
- [EVE Online moves to Python 3](https://news.ycombinator.com/item?id=49433328) — 290pts, 151c — a decade-long legacy migration on a live online game is a rare detailed war story; the operational constraints (can't take down EVE) make this a genuinely instructive systems case study
