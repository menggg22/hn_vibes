## 🔭 Depth — ml-infra / on-device ML / agent-systems

*What's the trend and what sparks curiosity.*

**ml-infra & on-device ML**: The direction is aggressively downward in resource requirements — a 28.9M parameter LLM on an $8 microcontroller is the logical endpoint of a trend that started with llama.cpp and is now reaching the embedded world. AMD is also closing the gap on CUDA-exclusive tooling, which matters for anyone trying to build infra that isn't Nvidia-dependent.
- [Running a 28.9M parameter LLM on an $8 microcontroller](https://news.ycombinator.com/item?id=49050512) — 36pts — worth exploring: what's the minimum useful task a model this small can reliably do, and does that unlock entirely new deployment categories?
- [Bringing PyTorch Monarch to AMD GPUs](https://news.ycombinator.com/item?id=49048689) — 59pts — Monarch is Meta's distributed training framework; AMD support means the open-weight training stack is less CUDA-captive than it was six months ago

**agent-systems**: Context engineering is becoming its own discipline separate from prompt engineering — the Claude 5 generation rules piece signals that how you structure long-horizon context is now the primary lever, not the individual prompt. The engineering management thread implicitly asks what humans do when agents handle the code.
- [The new rules of context engineering for Claude 5 generation models](https://news.ycombinator.com/item?id=49051361) — 118pts — the shift from "write a good prompt" to "architect a good context window" is the practitioner-level story of 2026 and this is a concrete example of what that looks like
- [Engineering management after the cost of code collapsed](https://news.ycombinator.com/item?id=49048212) — 106pts — if agents write the code, what does an EM actually own? The thread is thrashing toward an answer in real time

**Deep dives**:
- [GC and Exceptions in Wasmtime](https://news.ycombinator.com/item?id=48981665) — 151pts — Wasm GC + exception handling in the same runtime is genuinely hard; this is the spec-level plumbing that will matter when more agent sandboxing moves to Wasm
- [Spatial languages: Writing code in 2D](https://news.ycombinator.com/item?id=49007018) — 103pts — under-explored PL research direction; as AI generates more code, the question of what representation is best for *humans* to review becomes urgent
- [UK AISI / Caisi Preliminary Assessment of Kimi K3's Cyber Capabilities](https://news.ycombinator.com/item?id=49044492) — 122pts — government red-teaming of a frontier model's offensive cyber capability is a new genre of document; worth reading to understand what the evaluation methodology actually measures
