- [GLM-5.3-Flash](https://news.ycombinator.com/item?id=49449507) — 1104pts — a 313B model quantized to run on consumer hardware is the clearest proof yet that "on-device" and "capable" are converging; worth reading the comment thread for actual benchmark comparisons

- [Show HN: A lightweight, stateless database for agent memory](https://news.ycombinator.com/item?id=49450816) — 23pts — stateless memory is an interesting architectural bet; sidesteps the persistence complexity that makes long-running agents fragile
