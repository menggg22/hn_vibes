## 🔭 Depth — ml-infra / on-device ML / agent-systems

*What's the trend and what sparks curiosity.*

**ml-infra & on-device ML**: The boot-sector LLM is the reductio ad absurdum of on-device ML compression, but it sits alongside Mistral Large 4 open weights and the Qwen-Nintendo demo as a coherent theme: the floor for running capable models keeps dropping, and builders are probing how far that goes. Memdoor's multi-agent ensemble beating a frontier model on coding benchmarks with 8B-class weights is the more operationally significant signal if it replicates.
- [We're releasing the weights of Mistral Large 4](https://news.ycombinator.com/item?id=50289418) — 1706pts — open weights for a frontier-class model sets a new cost baseline for anyone self-hosting; worth tracking what fine-tunes emerge in the next two weeks

**agent-systems**: Malware using LLMs to triage and rank victims by financial value is the dark mirror of every "agentic AI" pitch deck — autonomous prioritization working exactly as designed, just for the wrong principal. The Claude Code supply-chain backdoor adds another layer: agents are now both the attack surface and potentially the attack vector.
- [Malware uses LLMs to rank victims by how much they're worth](https://news.ycombinator.com/item?id=50316531) — 228pts — the capability being exploited (autonomous triage + decision-making) is identical to what enterprise agent vendors sell; comments are grappling with that symmetry

**Deep dives**:
- [It's the Memory Latency, Stupid](https://news.ycombinator.com/item?id=50318720) — 103pts — with LLM inference costs dominating infra spend, memory wall arguments are suddenly more than academic; good time to revisit the fundamentals
- [Jepsen: ParticleDB 1.1.4](https://news.ycombinator.com/item?id=50316100) — 175pts — Jepsen reports remain the gold standard for distributed systems honesty; whatever ParticleDB broke is worth knowing before you deploy it
- [AI, Lean, and the Future of Formal Verification, with Lean Creator Leo de Moura](https://news.ycombinator.com/item?id=50290652) — 186pts — formal verification is having a quiet renaissance as LLM-generated code demands machine-checkable correctness; primary source interview is rare
