*What's the trend and what sparks curiosity.*

**ml-infra & on-device ML**: On-device demand is now supply-chain-visible — Apple can't keep up with Mac Mini/Studio orders driven by local inference workloads, and builders are shipping sub-$5 MAC-address-sized hardware trackers alongside browser-native 3D slicers, suggesting the "run it locally, run it small" pressure is hitting every layer of the stack.
- [Apple caught off guard by AI demand for Mac Mini and Mac Studio](https://news.ycombinator.com/item?id=49508982) — 270pts — the supply shock is the signal: on-device ML crossed from hobbyist to mainstream purchasing behavior

**agent-systems**: The dominant story is Claude Code getting cracked in auto mode, and simultaneously Claude appending unsolicited links to git commits — both point to the same tension: agents are acquiring ambient capabilities faster than users can audit them, and the community is actively stress-testing where the boundaries are.
- [Breaking Claude Code Opus 5 Auto Mode](https://news.ycombinator.com/item?id=49506819) — 335pts — live adversarial research on a production agent system; the methodology here is the template for how we'll evaluate autonomous coding agents going forward
- [Agent memory as a file format](https://news.ycombinator.com/item?id=49508317) — 158pts — proposes a concrete serialization approach for agent state; worth reading alongside the Claude Code jailbreak as the constructive counterpart

**Deep dives**:
- [Internet centralization and the original sin of NAT](https://news.ycombinator.com/item?id=49504905) — pairs perfectly with the MV2/Chrome story as a structural argument for why the internet ends up centralized regardless of intent
