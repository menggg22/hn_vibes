## 🔭 Depth — ml-infra / on-device ML / agent-systems

*What's the trend and what sparks curiosity.*

**ml-infra & on-device ML**: On-device is maturing from experiment to expectation — multiple builders today shipped local-inference tools assuming CPU-only environments as the baseline, not a fallback. The LFM2.5-24B-A2B model landing on the front page signals that mixture-of-experts architectures designed explicitly for device constraints are now a serious product category.
- [LFM2.5-24B-A2B: Built for fast on-device agents](https://news.ycombinator.com/item?id=50097369) — 282pts — a 24B active-2B model designed for agent workloads on-device; the active-parameter framing is the interesting bit — worth understanding what it implies for memory bandwidth

**agent-systems**: The "structure-first" framing in BlastLoop and the RDST database watcher both suggest builders are trying to escape the chaos of unconstrained agents by adding explicit scaffolding. The Garmin MCP Show HN still ranking shows agent tooling is spreading into embedded/IoT contexts.
- [Creating a Garmin "MCP"](https://news.ycombinator.com/item?id=50081045) — 55pts — model context protocol applied to a Garmin device; the interesting question is whether MCP becomes the USB of agent interfaces or fragments into vendor dialects

**Deep dives**:
- [AdFection: Targeted ads turned into a pipeline for zero-click mercenary spyware](https://news.ycombinator.com/item?id=50101813) — the technical pipeline from ad targeting data → device fingerprinting → zero-click exploit delivery is the story of 2026 and this appears to name and document it
- [Wanted to download an ISO, ended up writing a kernel exploit](https://news.ycombinator.com/item?id=50070625) — 344pts; the accidental-exploit genre is always instructive; kernel path from ISO download is a specific enough attack surface to learn something concrete
- [Prompt injection in HTTP headers: what 217M web responses show](https://news.ycombinator.com/item?id=50104310) — 81pts but low comments suggests it's being read more than argued; empirical data on prompt injection in the wild is rare and this is a dataset worth knowing
