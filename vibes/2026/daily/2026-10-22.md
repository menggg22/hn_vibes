## 🔭 Depth — ml-infra / on-device ML / agent-systems

*What's the trend and what sparks curiosity.*

**ml-infra & on-device ML**: DeepInfer's dominance today confirms that the community cares deeply about inference efficiency and model-layer independence from hosted APIs — on-device and self-hosted inference is no longer hobbyist territory. The 2B Android model doing on-device app control adds a second data point: edge inference for agents is becoming real.
- [DeepInfer: High-performance inference framework for DeepSeek models](https://news.ycombinator.com/item?id=50163277) — 2300pts — worth reading for the architectural choices around batching and quantization that let it beat vLLM on specific DeepSeek workloads

**agent-systems**: A three-way story today — Claude Duet shows multi-agent collaboration going mainstream-consumer, Patch the Planet shows agents doing coordinated security response at scale, and the "AI-written code you don't understand" Ask HN is the shadow side of all of it. Agents are shipping faster than the governance layer.
- [Patch the Planet: global response coordination as agents uncover vulnerabilities](https://news.ycombinator.com/item?id=50181175) — 224pts — on a day with multiple live CVEs, the idea of agents autonomously coordinating vulnerability disclosure across organizations is both compelling and terrifying
- [Claude Duet](https://news.ycombinator.com/item?id=50186037) — 288pts — two Claude instances running in parallel raises immediate architectural questions: shared context or separate, who arbitrates conflicts, how do costs compound

**Deep dives**:
- [Eight Bits of Trust: eMudhra's CA keys cracked in milliseconds](https://news.ycombinator.com/item?id=50177916) — read this to understand the full blast radius: if an intermediate CA's private keys are weak enough to crack in milliseconds, every certificate it signed is retroactively suspect, including any device firmware that pinned that chain
- [Compromised LiteLLM 1.107.0 on PyPI Installs a Credential Stealer and Backdoor](https://news.ycombinator.com/item?id=50181114) — LiteLLM is deeply embedded in agent stacks right now; if you're running any multi-model agent infrastructure, audit your dependency tree today before reading anything else
- [Using thousands of AI agents to uncover new leads in biological data](https://news.ycombinator.com/item?id=50180752) — the biological-data angle is underrated; agent swarms doing hypothesis generation over scientific datasets is a different risk/reward profile than code agents, and this is one of the cleaner real-world examples so far
