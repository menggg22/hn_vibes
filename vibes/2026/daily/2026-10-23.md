## 🔭 Depth — ml-infra / on-device ML / agent-systems

*What's the trend and what sparks curiosity.*

**ml-infra & on-device ML**: LLMs are quietly being deployed as inference components inside existing pipelines rather than as standalone products — today's stories show both the promise (formal verification at scale, confidence scoring) and the pitfalls (confidence scoring being misused as a reliability signal). The community is developing sharper heuristics for where LLM inference is load-bearing vs. decorative.
- [Using LLM for confidence scoring is a bad idea](https://news.ycombinator.com/item?id=50176082) — 200pts — a concrete, reusable lesson about calibration failure that every ML engineer deploying LLMs in pipelines should internalize today

**agent-systems**: Two competing visions of agent infrastructure landed today — a safety-focused private runtime for fleets and an open-source Claude Managed Agents alternative — suggesting the market is bifurcating between enterprise-controlled and open/self-hosted agent orchestration. The "how do you verify agent outputs" anxiety from the Ask HN thread bleeds directly into this space.
- [OpenShell – A safe, private runtime for fleets of autonomous AI agents](https://news.ycombinator.com/item?id=50198675) — 275pts — proposes sandboxed execution environments for agent fleets; the security model here is worth scrutinizing given today's PKI and trust themes

**Deep dives**:
- [LLMs are making formal software verification feasible at a much larger scale](https://news.ycombinator.com/item?id=50202217) — read alongside "shipping AI-written code you don't understand" — if this holds up, it's the answer to that anxiety; extremely early signal worth tracking
